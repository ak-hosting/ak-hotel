# AK Hotel

Eigenständige statische Portfoliodemo für eine ruhige Hotel- und Zimmeroberfläche.

```bash
npm test
npm run lint
npm run build
python3 -m http.server 8000
```

Die lokale Konfigurationshilfe verarbeitet keine personenbezogenen Daten, sendet nichts und erstellt keine Reservierung. GitHub Pages veröffentlicht die statischen Dateien; Docker ist nur eine optionale lokale Vorschau.

Live: https://ak-hosting.github.io/ak-hotel/
